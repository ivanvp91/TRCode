# TRCode v0.3.0 — аккаунты, хуки, свои команды, план и субагенты на любом хосте

## Аккаунты и вход

- У поставщика теперь книга именованных учётных данных: несколько ключей и подписочных
  входов рядом, один активный. `/accounts` показывает список, Enter делает строку
  активной, кнопки добавляют, переименовывают и удаляют; `/login` у подключённого
  поставщика открывает тот же список, а у неподключённого — форму в рамке модалок с
  полями «Ключ API» и «Имя» (ключ рисуется звёздочками). Переключение всегда ручное:
  автоматической ротации нет. Новый флаг — `trc auth login --name work`.

## Хуки и уведомления

- Внешняя команда на события `SessionStart`, `UserPromptSubmit`, `PreToolUse`,
  `PostToolUse`, `Stop` и `PreCompact`: JSON на stdin, код выхода `2` — блокировка с
  причиной из stderr. `PostToolUse` может дописать `[hook feedback]` к результату,
  `UserPromptSubmit` — добавить свой stdout к промпту.
- `notify` — команда, которая получает JSON хода последним аргументом, когда ход
  закончился.
- Хуки читаются из `~/.trcode/config.json` и из `.trcode/settings.json` проекта;
  проектный файл может добавить только `hooks` и заменить `notify` — не разрешения и не
  модель. Хуки из репозитория не запускаются без `/hooks trust` (отпечаток содержимого,
  правка файла требует нового одобрения).

## Свои команды

- Markdown-файл в `.trcode/commands/` (или `~/.trcode/commands/`) становится командой:
  `deploy.md` — `/deploy`, `db/migrate.md` — `/db:migrate`. Frontmatter `description` и
  `argument-hint`, `$ARGUMENTS` подставляется в тело, `` !`cmd` `` и блок ```` ```! ````
  заменяются выводом команды до отправки модели. Команды видны в подсказках композера,
  в индексе по `/`, в `/help` и в `/commands`.

## Правила разрешений и режим плана

- `/permissions` принимает шаблоны: `shell(git status:*)`, `shell(rm -rf *)`,
  `edit(src/**)`, `read(./.env)`, `fetch(domain:github.com)`, `*` — все инструменты.
  Проверка идёт проходами deny → ask → allow, первое совпадение в проходе побеждает:
  точечный запрет не перебивается широким разрешением и действует даже под `/yolo`.
- `/plan` (или `trc --plan`) делает сессию read-only: инструменты, которые что-то меняют,
  не предлагаются вовсе, в промпт добавляется секция `<plan-mode>`, а после ответа
  бар спрашивает — выполнить план, ещё планировать или выйти.

## Субагенты и навыки

- Субагенты ходят между провайдерами: список моделей помощников один на клиент, и
  отмеченная модель чужого хоста платится ключом этого хоста. Панель `/subagents` —
  вкладка на каждого подключённого провайдера.
- Потолок шагов помощника стал настройкой `subagentSteps`; по умолчанию его нет, как у
  главного цикла. Остановившийся помощник пишет, что продолжить можно follow-up'ом.
- Ничья между навыками больше не гасит навык: в историю уходит короткий список имён
  (`<skill-choice>`), и выбирает модель. Каталог навыков в промпте сжат до первого
  предложения описания — 6.8k символов вместо 16.5k на 57 навыках.
- Новый навык `.trcode/skills/desktop-control`: Windows GUI (UIA-паттерны, клики, ввод,
  снимки окна через `PrintWindow`) и браузер через DevTools Protocol без зависимостей.
  Foreground-действия требуют `-AllowForeground`, необратимые клики — `-Confirm`, каждое
  действие пишется в аудит-журнал.

## Исправлено

- Лимит, который снимается через дни, больше не высиживается: `429` с `Retry-After` на
  двое суток сразу заканчивает ход сообщением с временем сброса и подсказкой `/model`.
- Вопрос «ждать дальше?» больше не ломает нижнюю часть экрана: он часть кадра бара и
  снимается сам, как только в поток снова пришли данные.
- Список моделей субагентов сверяется с каталогом: исчезнувшая модель убирается из
  подписи и из сохранения, пустой каталог ничего не вычищает.
- «Всегда разрешать shell в этой сессии» теперь правда разрешает — и для команд на
  другую машину тоже (отдельный набор `sessionAllowRemote`).
- Агент больше не ходит на удалённые машины по своей инициативе: `ssh`/`scp`/`rsync`
  и клиенты БД с нелокальным хостом всегда спрашивают подтверждение, а в промпте есть
  раздел «Servers».
- Orca больше не запускает панель как opencode: отчёты не несут `sessionID`.
- Обрывок JSON в аргументах вызова больше не отравляет ход: на провод уходит `{}`,
  история хранит то, что пришло.
- Переключение панели и смена её ширины больше не оставляют вторую копию нижнего блока:
  область экрана очищается и пишется заново (`reanchorSeq`), отчёт о фокусе (DECSET 1004)
  не доходит до ввода как текст, неправдоподобный размер панели игнорируется.
- Панель уже 48 колонок не задваивает строку размышлений: ширина терминала берётся как
  есть, кадр обрезается по экрану.
- Секунды из живого хвоста долгих команд убраны — в блоке прогресса только слова самой
  команды; отсчёт остался в heartbeat молчащей команды.
- `TRCODE_FRAME_TRACE` включает журнал кадров для разбора жалоб на отрисовку.

## Проверка

Полный набор: 93 тестовых набора (все зелёные; `rate-test` дважды упал на
проверках отрисовки под нагрузкой полного прогона и проходит отдельно — 18/18). Новые сюиты — `accounts-test`, `login-form-test`,
`hooks-test`, `hooks-live-test`, `custom-commands-test`, `permission-rules-test`,
`plan-mode-test`, `remote-gate-test`, `subagent-stale-test`, `stall-prompt-test`,
`activity-test`.

## Установка и обновление

В существующей установке: `trc update` или `/update`, затем перезапустите CLI.

Для установки из архива релиза:

```sh
npm install -g https://github.com/ivanvp91/TRCode/releases/download/v0.3.0/trcode-0.3.0.tgz
```
