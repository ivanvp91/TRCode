# TRCode v0.2.2 — экран больше не пустеет в конце хода

## Исправлено

- Когда терминал не отвечает на запрос позиции курсора (`ESC[6n`), в конце хода
  композер просил сдвинуть экран на всю длину хода — в живом случае это 610 строк.
  Терминал выбрасывал переписку в скролбэк, и оставался пустой экран: ни ответа, ни
  строки ввода. Теперь замер позиции пересчитывает и точку отсчёта счётчика строк,
  «напечатано после» не бывает отрицательным, а сам сдвиг не может превышать высоту
  экрана.
- Запрос курсора молчит, в частности, в панели терминала внутри оркестратора (Orca):
  раньше пустота появлялась именно в таких панелях, а в обычном терминале — редко.

## Проверка

Полный набор: 82 тестовых набора. Новый блок `test/pin-test.mjs` — «a failed probe
does not scroll the screen away» (сюита 103 проверки).

## Установка и обновление

В существующей установке: `trc update` или `/update`, затем перезапустите CLI.

Для установки из архива релиза:

```sh
npm install -g https://github.com/ivanvp91/TRCode/releases/download/v0.2.2/trcode-0.2.2.tgz
```
